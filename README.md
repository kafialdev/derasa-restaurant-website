# DeRasa Restaurant Website

DeRasa Restaurant is a responsive restaurant website designed to support online food ordering and restaurant management.  
This project includes a customer-facing interface for browsing menus and placing orders, as well as an admin dashboard for managing orders and restaurant data.

## Features

### User Side
- Restaurant landing page
- Food and drink menu display
- Menu categorization
- Order placement system
- Order summary and confirmation
- Responsive design for mobile and desktop

### Admin Dashboard
- Admin authentication (login/logout)
- Menu management (add, edit, delete items)
- Order management
- Order status tracking
- Sales and order overview
- Simple and clean admin interface

## Tech Stack
- HTML
- CSS
- JavaScript
- PHP
- MySQL
